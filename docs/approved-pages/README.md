## November 10 proposal checklist

| Requirement | Implementation |
|---|---|
| Nine pages, Blog single template and empty state | Native block patterns, shared page template and dynamic Blog listing |
| Existing homepage and URLs | Homepage files unchanged; page IDs and parent relationships reused, including `/services/` routes |
| Separate End of Lease / Regular grids | Separate editable bedroom × bathroom matrices; studios supported |
| Deep/Spring | Estimator option; Regular grid × editable 1.5 multiplier; no new standalone page |
| Double storey | Editable 15% of base; excluded from carpet-only |
| Recurring Regular discount | Editable 15% of base plus surcharge; excludes add-ons and travel |
| Add-ons and carpet pricing | Oven, fridge, inside windows, balcony/patio, wall spots; bedrooms, lounge/living, hallway, stairs |
| Approved suburb zones | Explicit suburb list; zone 1 no fee, zone 2 editable AUD 30 per visit |
| Minimum, range, tax | Minimum after subtotal; ±10% endpoints rounded to nearest AUD 5; no GST added |
| Five custom-quote paths | 6+ bedrooms, 5+ bathrooms, furnished End of Lease, unlisted suburb, unavailable applicable rate |
| Estimate before contact | Server quote/range and expandable breakdown precede the enquiry form |
| Complete enquiry and recovery | Required contact/date/parking/consent, selected suburb, optional preferences/condition/pets/referral/notes; errors retain input |
| Save before confirmation | Database record and frozen quote first; idempotent retry key; real sequential ID-derived references |
| WhatsApp photo follow-up | Optional configured reference-prefilled link; no website uploads or automated WhatsApp messages |
| Owner and customer emails | Business and nominated owner destinations plus acknowledgement; business-domain sender settings and failure tracking |
| Admin | Existing enquiries retained; New/Contacted/Won/Lost plus legacy statuses; CSV export and frozen details |
| Navigation and mobile usability | Sticky desktop header, responsive menu, mobile Call/WhatsApp/Estimate bar, safe-area spacing, keyboard tabs and visible focus |
| Four-column footer | Business/nav/legal/contact, approved ABN field and payment-on-completion notice |
| Content accuracy | Labelled illustrative photos, missing-business placeholders, no invented reviews/ratings/credentials/prices or bond guarantee |
| Legal and exclusions | Legal/cancellation copy pending approval; no new accounts, payments, deposits, invoices, booking calendars or staff scheduling |

## Assets and editing

Service photographs are individual generated illustrative assets supplied in 640 px and 1280 px WebP variants, with responsive `srcset`. They must be replaced by approved client-owned photography. Poppins and Inter use the existing local font files. No complete mockup image is used as a page background or functional component.

Sections, headings, paragraphs, columns, images, buttons and FAQ details are editable native blocks. Dynamic prices, approved business details, Blog content and the estimator use shortcodes backed by the existing plugin. Checklist details progressively enhance to accessible tabs and remain readable as details elements without JavaScript.

The installer backs up previous page bodies before placing the new blocks. Existing body copy remains available in its backup/revision for review; it is not silently discarded or automatically treated as approved new copy.
